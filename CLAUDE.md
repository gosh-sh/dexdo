# Project Documentation Rules

Project specifications live in [`docs/`](docs/). The public REST API contract is [`docs/api-spec.md`](docs/api-spec.md); do not edit this file unless the task explicitly asks to change the public API contract.

Technical specifications live in [`docs/tech-specs/`](docs/tech-specs/) and must always be kept current. Update the relevant technical specification together with every code commit that changes behavior, architecture, data contracts, indexing, API implementation details, or operational assumptions.

Component README files must also stay current. When changing a service, crate, tool, deployment setup, or workflow, update the corresponding `README.md` in the same commit so it reflects the actual behavior and usage.
